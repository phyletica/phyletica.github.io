# Why Python?

---

-   Python is a general-purpose scripting language with a terse and clear syntax
    -   "Pseudocode that runs!"

-   It's versatile and in high demand in the job market

-   Huge ecosystem of pages that covers many fields

-   Industry standard for machine learning

---

## Can I use a different language?

-   Yes, but

    -   Class exercises will be in Python

    -   You still need to apply the concepts/practices we cover

    -   My ability to help will be reduced


***

# Will anyone be writing scripts in 10 years?

---

-   I don't know, but having the knowledge to will still be very useful

-   Using AI coding agents effectively requires a lot of coding knowledge

    -   For example, see [Erick Matsen's demo](https://matsen.fhcrc.org/agentic.html)
    -   You become a manager rather than an IC


***

# Can I use AI?

---

-   Yes, I encourage you to try using AI agents

    -   It's the new Stack Overflow

-   But, make sure you are understanding and leading the work

    -   It should help, not hinder, your learning
